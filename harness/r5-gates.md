# 하네스 게이트

## 게이트 순서

```txt
S1 →[M1]→ S2 →[M2]→ [G1 나] → S3 →[M3]→ [G2 나] → S4 → [G3 나] → S5 판정
```

- M = 기계 판정, G = 사람 승인
- 사람 승인은 3곳(G1·G2·G3)이고, 모두 내가 한다.
- 사람에게 넘어가기 전에 그 단계의 기계 판정을 먼저 통과해야 한다.

## 기계 판정 (S1~S3)

| 판정 | 단계 | 통과 조건 (전부 만족) |
|---|---|---|
| M1 | S1 | 섹션 5개(목적, 유저스토리, 데이터 필드, 권한, 상태값)가 모두 있음 · 유저스토리 번호가 `story-service.md`의 1~5 중 1개 이상 |
| M2 | S2 | 레퍼런스 5~8개 · 항목마다 `ui_url`, UX 포인트, UI 포인트, 반영할 것 4개 필드가 다 있음 |
| M3 | S3 | 키스크린 프레임 2~3개 · 모든 프레임이 390×844 |
