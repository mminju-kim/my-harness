# 하네스 오케스트레이터

- 오케스트레이터 = 메인 세션. 프로젝트 최상위 `CLAUDE.md`를 읽고 움직인다.

## 하는 일 / 하지 않는 일

| 하는 일 | 하지 않는 일 |
|---|---|
| 트리거를 알아듣고 대상 화면 id 정하기 | Figma에 직접 그리기 |
| 단계 순서대로 에이전트 호출 | s1~s4 파일 직접 쓰기 |
| 단계가 끝날 때마다 judge 호출 | 판정 결과 바꾸기, 판정 건너뛰기 |
| `state.json`, `gates.json` 기록 | 내 승인 없이 G 다음 단계로 넘어가기 |
| 게이트 앞에서 멈추고 요약 보여주기 | `docs/`, `rules.json`, `harness/r*.md` 고치기 |

## 게이트 앞에서 멈추는 방법

기계 판정을 통과하면 아래 4가지를 보여주고 멈춘다.

1. 이 단계에서 만든 것 요약 (3줄 이내)
2. 기계 판정 결과
3. Figma 섹션 링크 (S2부터)
4. "G<n> 승인" 또는 "G<n> 반려: <사유>" 입력 안내

- `gates.json`에 "승인"이 기록되지 않으면 다음 단계 에이전트를 호출하지 않는다.
- "좋아", "괜찮네" 같은 애매한 말은 승인으로 치지 않고 다시 묻는다.

## CLAUDE.md 범위

- 100줄 이하.
- 넣는 것: 트리거, 단계 순서, 게이트 멈춤 규칙, "하지 않는 일" 목록
- 넣지 않는 것: 판정 수치, 편집 범위 표 → `harness/r*.md`, `rules.json` 링크만

## 강제 장치

- `.claude/settings.json` 권한 설정으로 Claude의 쓰기를 막는다: `docs/**`, `harness/rules.json`, `harness/r*.md` (내가 직접 고치는 데는 영향 없음)
- 권한 설정은 하네스 파일을 모두 만든 뒤 마지막에 켠다.
- "승인 전 다음 단계 금지"는 1차에서는 훅 없이 `CLAUDE.md` 규칙 + `gates.json` 확인으로 지킨다. 훅이 필요한지는 R8 검증 결과를 보고 정한다.
